# Portfolio redesign: design plan

## Read the room
Mode: redesign-overhaul (owner: "update things as you please"). Archetype: experimental, type-led register.
Dials (Overview prose): Density 4, balanced reading; Variance 6, asymmetric chapters on a single rail; Motion 7, one continuous scrubbed signature plus a single load sequence.

## SPINES
1. Workbench: each project is a device on a desk; pick one up and it runs. Replay: pick up another.
2. Orbit of five: the projects orbit; scroll moves the camera around them. Replay: scroll.
3. Changelog: the portfolio is a git log; scroll writes the history and each commit unfolds into a project. Replay: scroll back un-writes it.
4. Hands on glass: the page is a phone; projects are apps on a home screen. Replay: open another app.
5. Signal line: one live line threads the page and morphs into each project's shape. Replay: scroll.
6. The spec compiles: the page starts as a written spec and compiles into UI as you scroll. Replay: scroll.
